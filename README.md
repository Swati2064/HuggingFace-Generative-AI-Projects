# 🤗 HuggingFace Generative AI Projects

A collection of hands-on projects built using the **Hugging Face Transformers** and **Diffusers** libraries. This repository demonstrates various Generative AI applications, including text generation, image generation, image-to-image translation, multilingual translation, audio generation, and Hugging Face pipelines.

---

## 🚀 Features

- 🤖 Hugging Face Pipelines
- 📝 Text Generation
- 🖼️ Text-to-Image Generation
- 🎨 Image-to-Image Generation
- 🌍 Multilingual Translation
- 🔊 Text-to-Audio Generation
- ⚡ Stable Diffusion Models
- 📚 Easy-to-understand Jupyter Notebooks

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/your-username/HuggingFace-Generative-AI-Projects.git
```

Move into the project directory

```bash
cd HuggingFace-Generative-AI-Projects
```

Install the required packages

```bash
pip install -r requirements.txt
```

## 📖 Project Notebooks

### 1️⃣ Hugging Face Pipeline
Demonstrates how to use the Hugging Face `pipeline()` API for common AI tasks such as text generation, translation, sentiment analysis, and more.

---

### 2️⃣ Multimodal Project
Explores multimodal AI models that work with different data types such as text and images.

---

### 3️⃣ Image-to-Image Generation
Generates new images from an existing input image using Stable Diffusion.

---

### 4️⃣ Text-to-Audio Generation
Converts text into speech or audio using Hugging Face models.

---

### 5️⃣ Stable Diffusion
Generate realistic images from text prompts using Stable Diffusion.

---

### 6️⃣ Multilingual Translation
Translate text into multiple languages using Hugging Face translation models.
